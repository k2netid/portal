# Zenith Theme

Zenith is a flagship ultra-clean, modern minimalist theme for JA-CMS designed for high-performance SaaS, corporate, agency, and creator publications.

## Key Features
- **Modern Typography**: Seamlessly powered by Plus Jakarta Sans and Inter with automatic dynamic Google Fonts pre-connection.
- **Glassmorphic Aesthetics**: Curated frosted card design, subtle atmospheric glows, and responsive layout.
- **Theme Host Contract Compliant**: 100% self-contained UI primitives (`ui/`) without depending on internal console components.
- **Full Route Resolution**: Complete support for all default public pages (Home, About, Blog, Post, Contact, Pricing, Solutions, Services, Careers, Achievements).
- **Reactive Customizer**: Fully integrated with the Theme Customizer, supporting live accent adjustments, CSS overrides, and 1-click color preset switching.
