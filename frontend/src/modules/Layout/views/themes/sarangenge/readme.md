# Sarangenge Theme

**Sarangenge** (bahasa Sunda: *tengah hari*) adalah tema situs **sekolah** untuk Jejakawan Core Engine — saudara filosofis **Janari** (*fajar*).

## Positioning

| | Janari | Sarangenge |
|---|---|---|
| Makna waktu | Fajar / awal hari | Tengah hari / matahari tinggi |
| Fokus | CMS reference, studio, brand editorial | Kampus, PPDB, prestasi, berita sekolah |
| Palet | Canvas Janari | Teal kampus + matahari emas |

## Design notes (2026 school web)

- Brand-first hero (nama **Sarangenge** sebagai sinyal hero)
- Bento grid untuk akses cepat (PPDB, program, prestasi, berita)
- Tipografi: Bricolage Grotesque + Figtree
- Gerak bermakna + `prefers-reduced-motion`
- Kontras ditujukan untuk orang tua/siswa di mobile

## Package

- Self-contained `ui/` (Button, Card, ThemeToggle)
- Routes bawaan: Home, About, Blog, Post, Contact, Pricing, Solusi, Services, Career, Achievement, Search
- Customizer schema inline di `theme.json` (belum setara kedalaman Janari)
